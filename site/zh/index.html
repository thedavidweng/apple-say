Apple Say

文字，开口成声。

Apple Say 是一款原生 macOS 语音合成与时间轴文本应用。使用系统声音编辑、试听和导出纯文本、LRC 及增强型 LRC。完全本地且免费。

下载 Mac 版 了解更多

免费开源 · 需要 macOS 14 Sonoma 或更高版本

每一行，每一字，都准时。

行级 LRC 与逐字增强型 LRC，自动适配语速。

时间戳保持不变。语音无法匹配时，Apple Say 会报告时序错误。

[00:02.00] 你好，欢迎使用 Apple Say。 [00:05.50] <00:05.70> 行级 <00:06.40> 对齐，<00:07.30> 逐字呈现。

支持的文档格式

使用 Mac 上的声音。

系统声音、Siri 自然语音，以及经你授权的个人声音。

按语言筛选已安装的声音，在语音检查器中调整语速和音高。系统声音会保留 macOS 朗读内容设置，包括可用的 Siri 自然语音。

了解个人声音

写作、试听、导出。

即开即写

打开即写。无需先保存即可试听和导出。

自适应对齐

自动识别纯文本、LRC 和增强型 LRC。无需切换模式。

语音检查器

调整语速和音高。导出 AAC、AIFF、WAV 或 CAF，并设置声道、采样率和比特率。

快捷试听与导出

⌘ Return 试听，⌘ . 停止，⇧ ⌘ E 导出。

系统与个人声音

使用 macOS 提供的系统声音和经授权的个人声音。

本地离线隐私

语音在本机合成。不联网，不埋点。

获取 Apple Say。

使用 Homebrew 安装，或下载 DMG 并将 Apple Say 移入应用程序。

brew install --cask thedavidweng/tap/apple-say

下载 DMG GitHub 仓库

预编译版本采用临时签名。若遇 Gatekeeper 拦截，右键 Apple Say.app 选择“打开”。
