Apple Say

文字，开口成声。

Apple Say 是专为 macOS 打造的原生语音合成与时间轴音频工作台。基于系统内置语音引擎，支持纯文本、LRC 及增强型 LRC 的编辑、试听与导出——完全本地离线，无需订阅。

下载 Mac 版 了解更多

免费开源 · 需要 macOS 14 Sonoma 或更高版本

每一行，每一字，都准时。

行级 LRC 与字词级增强型 LRC，按时间戳自适应调节语速。

时间戳只会被遵守，绝不被移动。当语音无法匹配时间轴时，Apple Say 会报告时序错误，而不是擅自修改你的文本。

[00:02.00] 你好，欢迎使用 Apple Say。 [00:05.50] <00:05.70> 行级 <00:06.40> 对齐，<00:07.30> 逐字呈现。

了解支持的文档格式

Mac 上的声音，尽归你用。

系统声音、Siri 自然语音，以及经你授权的个人声音。

按语言筛选已安装的 macOS 语音，在语音检查器中微调语速与音高。选择系统声音时，将完整沿用 macOS 朗读内容设置——包括系统通过默认语音通道提供的 Siri 自然语音。

了解个人声音

让文字发声所需的一切。

即开即写

启动即进入编辑态，免存盘直接试听与导出。

自适应对齐

自动识别纯文本、LRC 与增强型 LRC，无需手动切换模式。

语音检查器

语速、音高与导出格式(AAC、AIFF、WAV、CAF)，声道、采样率、比特率尽在掌握。

快捷试听与导出

⌘ Return 试听，⌘ . 停止，⇧ ⌘ E 通过原生存储面板导出。

系统与个人声音

调用 macOS 为 say 提供的任意声音，包括经你授权的个人声音。

本地离线隐私

本地完成合成，零埋点、零网络通信、零第三方运行时依赖。

获取 Apple Say。

通过 Homebrew 安装，或从 GitHub Releases 下载 DMG 并拖入应用程序文件夹。

brew install --cask thedavidweng/tap/apple-say
